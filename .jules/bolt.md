## 2026-03-05 - [Memoizing large React DOM Grids]
**Learning:** In the `PYQHeatmap` component, a large nested loop `filteredTopics.map(topic => filteredYears.map(year => ...))` was unconditionally evaluated on every single render. Because clicking on any cell triggered a state update (`setModalData`) to open a drill-down modal, the entire component would re-render. This caused thousands of `div` elements to be needlessly re-calculated by React on a simple modal open interaction, causing major sluggishness.
**Action:** Always wrap large, dynamically generated DOM grids (especially those derived from Cartesian products like Topic x Year) in a `useMemo` block, strictly binding them to their respective data arrays (`filteredTopics`, `filteredYears`, `cellMap`) and stable callbacks (`handleCellClick`).
