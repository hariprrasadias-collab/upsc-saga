## 2024-05-20 - Cross-Site Scripting (XSS) via dangerouslySetInnerHTML and innerHTML
**Vulnerability:** The application was using React's `dangerouslySetInnerHTML` in `AnkiDojo.tsx` to render flashcard content, and `element.innerHTML` in `TriangulationHistory.tsx` to render SVG diagrams generated by Mermaid without any sanitization. This allowed execution of malicious scripts.
**Learning:** Even internal or semi-trusted data sources (like flashcards or generated Mermaid SVGs) can contain malicious payloads if not properly sanitized before rendering. Using raw DOM injection without a library like DOMPurify makes the application highly susceptible to XSS.
**Prevention:** Always sanitize any dynamic HTML or SVG content using `DOMPurify.sanitize()` before passing it to `dangerouslySetInnerHTML` or `innerHTML`. When sanitizing SVGs, explicitly pass `{ USE_PROFILES: { svg: true } }` to preserve SVG structure while removing dangerous tags.
